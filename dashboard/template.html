Trajectory is a bootstrap-evidenced recent-vs-prior 12-month comparison (stage 6 of the pipeline), not a raw slope — a direction only shows when the confidence interval on the shift excludes zero. Emerging Issue is a separate, narrower signal (a recent 60-day negative-review spike, tested for only 650 of 19,154 locations where review volume allows it) — kept distinct from Trajectory rather than folded into it. Aspect sentiment is a transparent lexicon heuristic (VADER + keyword taxonomy), not a contextual model; the "weakest aspect" flag now requires the location to have its own evidence for that aspect, not just a peer-prior fallback. Operational Profile (hours-listing completeness) is shown as context only — it passed 5 of 6 evidence-gate checks but was kept out of the score because it measures listing maintenance, not observed operating consistency. LHI is the hybrid-candidate version selected for having the highest agreement with the business-rule, statistical, and ML-informed alternatives (see the accompanying notebook). Historical Yelp data through 2022-01-19 — not a claim about current operating conditions. The Geographic Risk map requires an internet connection — it loads tiles from OpenStreetMap's standard tile server (a free, best-effort demo endpoint suitable for this scale of use, not for high-traffic production deployment) and a CARTO dark basemap in dark mode. Every other view — KPIs, charts, filtering, the location table, and the detail drawer — works fully offline from the data already embedded in this file.
